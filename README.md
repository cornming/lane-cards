# 三路卡陣

致敬 2012 年網頁卡牌遊戲「卡卡們的大亂鬥」玩法的原創單機版。角色、卡名、數值和美術都是重新設計，只沿用玩法機制：

- 三條路、每條 10 格的橫向戰場，雙方英雄分站兩端
- 每張牌有「待機值」，每回合減 1，歸零才能出牌
- 單位召喚後自動前進、自動攻擊，玩家只決定「放哪裡、什麼時候放」
- 戰士、遊俠、法師、牧師四個職業，各有專屬技能牌
- 近戰、射擊、火焰、冰結、雷擊、神聖、暗黑、牆八種攻擊類型
- 先制、反擊、飛行、警戒、衝鋒、狙擊、治療、加速、直擊等能力

## 成長系統

- 主城：冒險地圖（5 章 15 關）、練兵場、牌組營帳、圖鑑書庫、鍊成工坊、英雄大廳
- 戰後拿金幣、經驗與卡牌；升級提高英雄生命
- 收藏卡牌自由組牌（15～25 張），重複卡可鍊成升星
- 進度存在瀏覽器本機，換瀏覽器或清除網站資料會重置

## 怎麼玩

直接用瀏覽器開 `index.html`，手機和電腦都可以。開啟 GitHub Pages 後也能線上玩。

## 開發

- 整個遊戲是單一檔案 `index.html`，不需要建置。
- `node tests/sim.js [場數]`：讓電腦對電腦自動對戰，檢查規則不會卡死，並列出各職業勝場。
- 版本號在 `VERSION`，遊戲左上角也會顯示。

## 版本與發布

推上 `main` 後，GitHub Actions 會：

1. 跑模擬測試。
2. 如果 `VERSION` 的版本已經發布過，自動把修訂號 +1，同步更新 `index.html` 裡的版本號並提交。
3. 建立對應的 tag 與 GitHub Release，Release 說明取自 `CHANGELOG.md` 對應段落。
4. 部署到 GitHub Pages。

要升次版號或主版號，手動改 `VERSION` 和 `index.html` 的 `VERSION` 常數，並在 `CHANGELOG.md` 加上對應段落。

變更紀錄見 [CHANGELOG.md](CHANGELOG.md)。
